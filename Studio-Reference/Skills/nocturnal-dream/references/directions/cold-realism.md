# 冷峻现实主义

## 可复用提示词

> 为 Nocturnal Dream 构思一个冷峻、写实的当代场景。从一个目标抖音观众熟悉的城市、建筑或经验入手，改变一项环境条件或尺度关系。变化可以很极端，镜头仍像人在现场拍到。优先考虑低照度、漫射天光、冷色实景灯与可读的暗部。用材质、视距和现场声音交代变化的分量。让观众自己感到寂静、疏离或敬畏。现实的变化可以从首帧就已存在。先给一个可拍的核心画面，以及它为什么改变了熟悉地点的感受。

**判断。** 即便拿掉冷色调，这个空间和改变后的关系也应该成立。需要压低情绪时，可以只留空旷、距离或环境声。以《上海，暴雪之后》的空间发现为参照，题材和拍法随新场景而变。
