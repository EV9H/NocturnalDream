# 史诗巨构

## 可复用提示词

> 为 Nocturnal Dream 构思一个由巨构主导的场景。选一个能和目标抖音观众产生联系的具体建筑形制、地方地貌、工程传统或当代基础设施。设想它被推演到城市或地貌尺度时，改变了什么空间关系。巨构可以是现代工业、未来工程，或古代中国的赛博朋克、蒸汽朋克及混合技术史。先给一个能感到体量的实拍式机位。用遮挡、重复构件、真实可比的比例尺、阴影或声音传播让观众逐步看懂体量。巨构的用途可以通过结构或一个可观察的后果体现。给观众足够时间感到重量和距离。

**判断。** 巨构要在同一个镜头里与地貌、建筑或光线发生关系。建筑本身即可承担文化锚点；空景成立。选择最适合世界的技术逻辑，让机械部件、材料和尺度为画面服务。
