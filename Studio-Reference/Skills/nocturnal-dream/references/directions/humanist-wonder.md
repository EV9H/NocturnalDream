# 温情生活奇想

## 可复用提示词

> 为 Nocturnal Dream 构思一个温情、克制的生活奇想。从目标抖音观众熟悉的一段具体生活经验出发，例如回家、邻里关系或共享的日常空间。改变一条空间或环境条件，让原本隔着一段路或一层距离的人、地方或感觉，能在同一个镜头里接上。用小动作、距离和自然声音收住情绪，给人物保留继续过日子的分寸。先讲观众看到什么，以及哪个具体瞬间让熟悉的经验有了新的重量。

**现有参照。** 《出站就是家》把高铁站台和一户户人家的门放在同一条线上，行李箱轮磕过门槛的声音把春运到站和回家接在一起。《握手楼松开了》用阳光、街巷和塑料凳挪开的半步呈现一点松快。两者保留为本方向的概念参照，仍处于讨论阶段。该方向可以带有温情公益短片的气质。 [原提案聊天](codex://threads/01a1edd0-a928-7ea2-98f1-c727491f8241)

**判断。** 让情绪来自特定空间和人物反应。给观众留出自己的解释，避免把结尾写成标语或全员一起感动的场面。
