# 梦核 / 阈限空间

## 可复用提示词

> 为 Nocturnal Dream 构思一个梦核场景。先选目标抖音观众在当代中国有机会认识、能凭声画认出的空间，例如学校、交通节点或公共建筑。只改变一条梦中才会有的空间、时间或感知关系。写出人站在那个位置会先看见什么，在什么时候察觉空间和记忆接不上。用真实尺度、材质、实景灯、远声和回响拍出它。情绪可以是认出旧地方后的空落、半夜醒来的恍惚，或一种平静的不安。场景可以全空，变化也可以一直存在。

**判断。** 具体到能认出这类地方。雾、噪点、故障画面和滤色按镜头需要使用，核心关系要能通过空间或声音成立。让观众在这里待上片刻，有机会感觉到这种变化。

## 本工作室的梦核画面基准 · 2026-11-19

按 Evan 在《还有一分钟就熟了》审片后明确的偏好，以 Backrooms 的空间迷失感、当代中国的阈限场所和旧影像质感共同定美术。第一张定调图就应让人认得这里，又拿不准下一步会走到哪儿。可在明亮白天成立，也可以很安静。

- **选地点与机位。** 从人平常会经过或等候的地方起步，例如少年宫舞蹈教室外的换鞋区、散场后的县城影楼楼梯。留下能指认年代和用途的细节。从门口或转角看进去，给观众一条可追踪的路线；用重复的入口、失去终点的纵深或被截断的视线，让方向感在某处失效。每场选一个主要手段。
- **布光与声音。** 选场所自带的光。例：顶灯把近处座椅和远处空地照得一样亮，走廊尽头再折进另一片同色光。听点留在门口，近处能听清一盏灯的镇流声，转角后有一声鞋底摩擦却迟迟无人经过。按具体地点选择声源。
- **旧影像。** 先选一种拍摄介质并给它一张质感参考。约 2010 年的场景可试家用数码相机录像：灯管高光轻微溢白，暗部有少量彩噪，红色塑料边缘稍软。按实际可见光源布置偏色，保住文化锚点和门框边界。若选 VHS，另定磁带来源和整套纹理。滤镜强度在同一张图上 A/B，避免用低交付分辨率代替调色和纹理设计。
- **付费前看一张竖屏定调图。** 选一张中国场所实照定年代与材质，一张阈限空间参考定视线，一张旧影像参考定色彩与纹理。可以一图兼任。先看干净版，指出视线在哪一步失去方向；再看旧影像版，判断它是否让人相信这是某台旧机器留下的片段。纯文字难以验证这两件事。

经验来源：[《还有一分钟就熟了》Take 01](../../../../../Scenes/One-Minute-to-Harvest/PRODUCTION.md)。用户反馈原片缺乏梦核美术。上述数码相机配方是下一次定调的提案，尚待画面验证。

## 从摄影参考推到空间设计

在提案里给每件参考作品分配一个可执行决定。写出观察对象、借用的方法，以及它在本场景里改变的那条边、那块光或那个声音。

| 参考 | 转成拍摄与美术决定 |
| --- | --- |
| [Gregory Crewdson，《Twilight》中的积水客厅](https://art.nelson-atkins.org/objects/73902/untitled) | 把异常落在建筑与物件的接触面上。先确定它如何遮挡家具、截断光线或改变反射。定调图在同一画面内给出正常比例和它受影响的证据。 |
| [Jacques Tati，《PlayTime》](https://www.criterion.com/current/posts/3337-jacques-tati-composing-in-sound-and-image) | 用成组重复的隔间线条和反射安排误读。让观众先把一扇门认成出口，再从门后的地缝和家具看懂它通向另一间同样的房间。把发现留在宽景里，让观众自己扫到。 |

把现实改写到建筑本身。可以让承重墙错位、让两间教室共用一排窗，也可以在镜头内改变空间。若拓扑改变，先画明改变边界、固定参照、受影响的透视线与接触阴影。改变可以早已完成，由机位揭示，也可以发生在镜头内。后一种先用两张关键帧或简单灰模画出前后状态，检查哪几条线如何接续。设计阶段就选定一个旧影像介质，最后再校准纹理强度。

### 定调例 · 《隔壁也是六年二班》

约 2010 年的暑假下午。从后门以站立眼高平视，约 28 毫米等效。左侧前景留一截掉漆的豆绿色门框；中间是水磨石地、按竖列排列的黄木课桌，右边是铝窗漏进来的粉白天光。视线穿过讲台，本应落在黑板上。黑板所在的墙从地面整面缺失，地缝、桌脚投影和右侧窗列连进下一间同样朝向的教室。后两间只露出窄窄的桌列和半面黑板，最远一层被日光冲淡。固定前排桌子大小、窗柱间距与遮挡顺序，避免空间读成镜面反射。近处一张忘收的透明塑料桌垫轻翘，远处响一小段放学铃。用旧数码录像的高光溢白、轻微青绿色偏与暗部彩噪完成质感。先把定调图缩成手机大小，确认前门框、第一排桌子和第二间教室能分三层读出来。本例为原创书面方向，待定调验证。
