# 创作方向库

每个文件都是一份可单独调用的创意提示词。方向决定镜头怎样理解这个世界，也决定结尾留下哪种感受。共同的 Altered Reality、文化锚点、电影写实和制作规则在 [技能入口](../../SKILL.md)。

| 方向 | 适合什么时候用 |
| --- | --- |
| [冷峻现实主义](cold-realism.md) | 想看现代生活在某个异常但可信的条件下，变得安静、疏离或压迫。 |
| [反乌托邦](dystopian-realism.md) | 想看一种社会或基础设施规则，如何冷静而具体地改变生活。 |
| [梦核 / 阈限空间](dreamcore.md) | 想看某种熟悉的当代空间，以梦的时间或空间逻辑重现。 |
| [史诗巨构](epic-megastructure.md) | 想让建筑、工程或地貌的体量成为镜头主角。可以是现代工业，也可以是古代中国的另类技术史。 |
| [温情生活奇想](humanist-wonder.md) | 想看一个想象中的空间变化，如何连接具体的人和他们的日常。按需启用。 |

按本轮 brief 匹配方向。明确点名时只读那个文件。要比较多个方向时，各读各的提示词，分别提出概念。只有在用户要求融合时才合用。开放脑暴仍按 [脑暴章节](../concept-brainstorming.md) 展开；温情生活奇想由用户点名或明确要求相应温情时启用。新方向沿用同样的结构，独立保存并在这里登记。

**调用示例**　`用 $nocturnal-dream，方向选反乌托邦。用中文只给一个当代中国的场景概念，先讲核心画面。`

| 新增方向 | 选择条件 |
| --- | --- |
| [浪漫记忆 / 城市余像](romantic-memory.md) | 想让一个具体地方的两个时刻相遇，让观众体会依恋或错过。 |
| [超现实装置 / 编辑式空间](surreal-editorial.md) | 想从一个熟悉的展示或使用秩序出发，让形体变化揭示场所的另一种用途。 |

世界方向负责「发生什么，以及为何有感觉」。选定后从[六种摄影方法](../photographic-territories.md)挑一个最适合观看问题的手段。自然主义逆光也可拍反乌托邦，人工色光也可拍一场温柔的告别。只在能解释它对这场戏的贡献时借第二种方法。

**复合 brief 的读法。**「冷、白天、无人、中国沿海巨构」中，巨构决定世界关系，白天与无人是拍摄条件。「冷」可先用冬季散射光、空间距离或环境声音表达；用户明确指定冷峻现实主义时，再把它当作所选世界方向。交稿时直接写出采用的解释。
