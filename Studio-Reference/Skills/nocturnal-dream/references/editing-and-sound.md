# 竖屏节奏、剪辑与声音

### 5.3 剪辑与声音

#### 5.3.1 第一眼、发现、停留

- **第一眼就给画面内容。** 手机竖屏下，观众一眼能找到主体，同时看见文化锚点或现实变化的一部分。锚点本身足够有力时，可以稍后揭示变化。可以开在动作已发生的时候，或直接给出最有辨识度的关系。片头、空转运镜和可替换的风景交代从可删项开始审。
- **设计视线的先后。** 为每个观看节拍指定一个主视觉重心、一个次要线索。用明暗、轮廓、运动、遮挡或透视引导视线。检查竖屏界面安全区，避免无关亮点抢走重心。焦点从 A 转到 B 时，观众应该看得懂两者的空间或因果关系。
- **每一段都有发现或感受。** 先画三张构图，标出第一眼看什么、何时看懂变化、最后留下什么感受。可以是一镜内的三次视线变化。换机位应当带来新关系、新尺度或新的情绪距离。停留给观众读尺度、辨认细节或听完余声的时间。删除一段后如果感受和理解都一样，试剪短或重拍。
- **Wow factor 出自核心关系。** 让观众从熟悉的锚点看懂一次尺度、时间、材质或功能上的变化，并用一个看得见或听得见的后果落地。宏大可产生敬畏，安静也可以使熟悉的地方突然有分量。单场景可以只用一次发现成立。先让核心画面静音、去字幕也读得懂，再比较声音怎样加深感受。
- **用版本检验节奏。** 比较「首帧直接给出核心关系」和「首帧给一半，随后揭示」时，保持后半和声音一致。发布前做手机观片，发布后结合开头留存、平均观看时长、完播与评论所提到的具体细节判断。时间点按素材定。观察结果只用于具体平台、片长和版本的比较。

#### 5.3.2 环境声、事件声与音乐

- 先搭环境底声，再挑一个有方向和距离的关键声音。脚踩雪、报时钟或金属共振可以预告下一眼，也可以在画面揭示后确认体量。用音色、远近和短暂的留白建立节奏。用手机外放确认关键声在低频有限时仍然可辨。
- 先试听环境声版。音乐有明确任务时再加，例如给运动一个脉冲，或在认出场景以后延长情绪。比较音乐早点进、揭示后进和纯环境声时，保留同一画剪。让关键声音在混音里有空间。选用原创或有合适授权的音乐。
- 字幕用于必要的信息。单场景可以让观众在图像、动作和声音里完成发现。Sequence 用跨镜头的感知递进组织节奏，Film 随剧本的因果和情绪转折设计。

**例｜《上海，暴雪之后》**。开头让步线直接经过快被雪埋没的护栏。近处先读雪深，再沿视线跨过江面，认出陆家嘴和对岸屋顶上的同一场雪。结尾留出看清对岸的时间。声音从近处的雪脚步转到江面的远声。Take 07 的画面记录支持这条观看路径，开头缩短约一秒是待比较的剪辑实验；声音方案和观众反应待验证。[Take 07 画面记录](../../../../Scenes/Shanghai-After-the-Snow/REVIEW.md#take-07--walking-pov-picture-review)

### 5.3.3 声音和音乐从哪个位置听

先写一句听点，例如「耳朵在船舷内，水线几乎贴耳，石桥另一边听不真切」。按需要写四轨。每轨都应能回答声源、距离、出现条件和退出方式。

| 轨 | 怎么设计 | 怎样判断 |
| --- | --- | --- |
| 场所底声 | 选一个连续底和一处画外方向。封闭走廊保留早期反射，室外开阔处给远声余地。机位穿过门洞时调整遮蔽与尾音。 | 闭眼能否说出自己在里、在外、靠近什么？切镜后是否仍在同一世界？ |
| 动作与接触 | 找最能证明重量或材质的瞬间。写清起音、受力、松开及尾音。接触可与画面同步，远处可延后听见。 | 若水、布和铁都靠一次撞击低音表达，独听近轨，恢复材质自己的摩擦或振动。 |
| 异常或母题 | 让改变的世界借用地点已有的声音。重复时改距离、密度或音色的一项。刻意静默时保留可察觉的环境底。 | 拿掉该声，观众少理解哪件事？它与其他声源能否被区分？ |
| 音乐 | 先决定作用是建立脉搏、延长余味、还是让声画有意错位。写节拍密度、音色、音域、进入点、退出点及留给关键声的位置。 | 同一音量感下比较环境声版。若旋律替观众宣布「此刻感动」，试去掉和声解决，留一次呼吸或尾音。 |

**原创音乐写法。** 想让工业巨构产生缓慢脉搏，可以从绞盘转动的间隔取拍，取摩擦音的泛音作持续音。需要亲密时，可用留有间隔的单音钢琴，最后一个音随画面外的脚步自然衰减。EDM 适合有重复机械或身体节律的世界；先定一次需要对齐的重音，其他动作允许错拍。序列中可让同一节奏从现场声慢慢变成乐器，再还给下一个地点。纯环境声同样可作完整成片。

**示范 cue｜水位留下的街。** 开场贴耳是船板旁的小水拍，桥外有远处的人声。看到下方旧铁环时只有水声。最高环受力的一刻，一小段麻绳擦过铁，近、干、短；镜头漂过后，桥下水声多留一拍。备选配乐从摩擦尾音接出一个很轻的持续音，到窗沿处收掉。固定画剪比较两版，记录是否更容易看懂最高环在使用。此处时间由动作决定。

**交付给剪辑。** 标明原生生成音、现场录音、拟音、原创或授权音乐各自的来源。能分轨时保存底声、关键声与音乐，写入点和尾点。分别做静音看画、闭眼听场所、手机单声道外放三遍；手机丢了巨构低频时，可补同一机构的中频摩擦或共振。记录实际听见的缺陷；无音轨的画面测试把声音标为待验。

**远声的尺度检验。** 如果听点高在栈桥栏杆边，几十层楼下水滴的着水声很难从浪声里分辨。可让近处滴水先敲到栏杆支架，再把墩脚的浪保留为遥远的连续声。若刻意把微声放大成主观听觉，给它一个进入和退出的条件。
