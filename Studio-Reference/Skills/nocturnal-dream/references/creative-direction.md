# 创作方向与场景立项

## 01｜项目北极星：账号到底是什么

### 1.1 一句话定位

**以电影化写实呈现被改变的现实。从与目标抖音观众有联系的文化锚点出发，改变其中一个条件，让熟悉的世界唤起新的感受。先做场景，再发展视觉组曲和原创电影。**

账号是原创视觉世界与电影的长期研发工作室。AI 是制作工具，不是内容的唯一卖点；**眼下主线是 Scene / Visual Exploration，不是微剧情账号**。

### 1.2 可识别的品牌承诺

1. 每支作品先明确**观众认得什么、现实发生了什么变化、这次变化为何会让观众有感受**。
2. 画面以空间、时间、材质、光源和人与世界的关系建立可信度。
3. 可以有人、可以无人；可以有超现实异常、也可以是完全物理可信的极端场景。**不强制每条都有主人公、道德寓意或反转。**
4. 保留六条 Visual DNA 和 A/B/D 风格，但根据题材决定如何运用，避免每条都长得像同一座阴暗地铁站。
5. 构建可扩展的世界、声音与视觉母题，逐步积累 scene library → sequence / bundle → long film 的原始素材与经验。

### 1.3 目标受众与内容场景（待实测）

- 主要候选：喜欢电影、音乐、潮流视觉、城市夜景、精致情绪短片的 18–35 岁短视频用户。
- 用户需求：情绪共鸣、审美刺激、可分享的奇异情境、值得收藏的短片。
- 平台假设：抖音 / TikTok 竖屏为主，Instagram Reels / 小红书作延展。各平台的内容比例和发布节奏应按数据而非直觉决定。
- 创始目标：用**能连续做 100 条**的创作系统，找到自己的审美指纹。

### 1.4 明确不做

- 把所有 5–10 秒 AI 视频硬塞成起承转合、角色转变、煽情文字或「跟随梦想」的励志寓言。
- 为一张好看的奇观画面临时编造不可信的人物动机或行动；未设计为何安全，就让人物走进海里。
- 空洞地堆叠赛博、巨物、寺庙、雨夜等流行标签，缺少具体文化依据和有意图的摄影设计。
- 每支都要有一个异常、一个反转、一个人物；或把「10 秒」误当成内容类别。
- 泛滥霓虹、假 HDR、油亮肤质、失控变形、无来源的镜头运动、权利不清的素材。
- 把文化当成可替换的布景，或只靠奇观、反转、煽情台词和配乐替观众规定感受。

### 1.5 核心内容主题 / Altered Reality

**植根现实的想象 / Reality-rooted Imagination = Familiar Reality × Extraordinary Alteration × Emotional Recognition.**

- **文化锚点（Cultural Anchor，必选）。** 每个场景至少有一个与目标抖音观众有联系、能通过画面或声音感知的具体文化锚点。可以是外滩天际线、许多人记得的校园广播、地方建筑、节俗、历史意象或传统工艺。观众可以通过亲身经历、集体记忆或文化传播认出它。写清与你想触达的观众有什么联系，以及现实的改变如何作用在这个锚点上。
- **生活痕迹（可选）。** 人物、窗灯、磨损、摊位和日常动作可以帮助表现尺度或情绪。空景也可以由地标、建筑形制、声音或文化意象独立建立联系。
- **现实的改变。** 可以改变天气、时间、尺度、历史走向，或让梦中的感知进入现实。让这一变化作用在观众熟悉的细节上。梦核可以从校园广播和空走廊的记忆出发。**古代中国巨构（赛博朋克、蒸汽朋克或两者融合）**可以从城门、治水、节令和市井生活出发，想象这些系统在另一条技术史上如何长成城市尺度的工程，又如何改变普通人的日常。题材与风格服务于那段经验。
- **情绪上的认出。** 明确观众会在什么时刻感到怀念、宁静、眷恋、敬畏或失落。用可观察的光线、距离、动作、环境声和停留时间，让情绪从场景本身发生。天马行空的设定也按实拍电影来导演，维持空间、材质和声音的可信度。

**立项三问。** 目标抖音观众会认出哪个文化锚点，它与他们有什么联系？改变能如何被看见或听见，并遵循什么规则？哪个镜头或声音让这段变化触及一种说得清的情绪？如果换成任意文化符号都一样，重新选择能参与场景构思的锚点。无需字幕、旁白或煽情配乐就能体验到核心关系。

**基准案例。** 《上海，暴雪之后》从上海老小区的步行测试发展而来。试拍中的街道辨识度低，雪深也读不出来，随后将视点移至外滩，保留黄浦江、外滩护栏和陆家嘴的真实关系。观众从脚边的积雪看到对岸熟悉的天际线，才感到这座城市变得多么安静。这个转向源于项目对话 [《启动首部短片》](https://chatgpt.com/c/6afc48b6-32e0-83ec-b8e3-4f3d7480676e)，制作记录见 [Shanghai After the Snow](../../../../Scenes/Shanghai-After-the-Snow/REVIEW.md)。观众感受尚待验证。

## 02｜内容理论：STEPPS 用于创作决策

| 维度 | 创作问题 | 视频内可执行的机制 | 常见失败 |
|---|---|---|---|
| S / Social Currency 社交货币 | 分享它会让我显得有什么品味或发现？ | 独到审美、反直觉揭示、令人想转给朋友的意象 | 自夸式「我做得很厉害」 |
| T / Triggers 诱因 | 生活中何时会再次想到这个系列？ | 雨夜、地铁、凌晨、某首音乐、周五的固定栏目 | 一条火后无记忆锚点 |
| E / Emotion 情绪 | 观众看完身体感受到什么？ | 惊叹、渴望、悬念、释然、苦甜情绪 | 只有漂亮画面，没有情感变化 |
| P / Public 公共性 | 能否被看到、模仿、识别？ | 系列符号、可参与的挑战、辨识度强的封面母题 | 形式复杂无法复述 |
| P / Practical Value 实用价值 | 是否值得收藏或转给需要的人？ | 少量穿插 behind-the-scenes、创作拆解 | 教程取代作品，削弱品牌调性 |
| S / Stories 故事 | 若是故事影片，观众能否复述因果与选择？ | 角色 + 动机 + 变化；世界组曲可仅暗示背景历史 | 为奇观硬塞假剧情或勉强励志 |

**每条聚焦 2–3 个主驱动**，其余可为空。高唤醒情绪更常触发传播，但长期品牌还需要审美一致性和对人物的情感投资。

### 2.1 传播框架必须服从内容类型

**Altered Reality / Scene**：先找适合这段经验的 Emotion（如怀念、安静、敬畏），再按场景考虑 Triggers（会让观众想起作品的生活线索）、Social Currency（有情绪或文化意义的发现）或其他驱动。

**Visual Sequence / Worldbuilding**：靠系列母题、熟悉的世界规则、视听主题和逐渐增长的信息密度形成 Triggers / Public / Emotion；不是每一个镜头都要有剧情冲突。

**Narrative Film**：当我们确实要讲故事，再用 Stories、Emotion、Social Currency 等深入设计角色动机、因果和终局。

**通用提问**：「这条内容使观众体验到了什么独特而可以转述的东西？」优先选 2–3 个 STEPPS 驱动，不规定每条都必须有 Hook→Twist→Moral。

### 2.2 创作阶梯 / THE THREE-STAGE LADDER（核心路线）

| 阶段 | 作品单元 | 工作目标 | 是否必须有剧情 | 升级条件 |
|---|---|---|---|---|
| **Stage 1 · SCENE**（现在） | 独立高概念场景；常见 5–20 秒，也可以更久 | 建立鲜明视觉概念、可信世界、镜头与声音的质感，探索不同题材 | **否** | 已有足够原创、可复用、QC 合格的场景，以及可辨识的视觉母题 |
| **Stage 2 · SEQUENCE / BUNDLE**（下一步） | 多场景组合、视觉组曲、音乐影像；长度由内容决定，常见 30–120 秒或更长 | 建立世界内部一致性、尺度变化、节奏、场景间逻辑与声画推进 | **否**，可以有隐含叙事但不强制人物弧线 | 世界设定、视觉与声音能跨场景维持；组合后整体优于片段堆砌 |
| **Stage 3 · NARRATIVE FILM**（长期） | 有角色、因果和真实戏剧结构的完整短片或长片 | 以已成熟的视觉语言为剧情服务，处理背景、动机、选择、后果 | **是** | 故事文本独立成立；世界规则、角色行动和制作能力能支持完整影片 |

**这是能力进阶，不是产出期限。** 可以在 Stage 1 试少量长片技术，但账号初期不要为了「看起来像导演」强行编剧。长度服务概念，不由模型单次输出时长决定。

### 2.3 Scene-first 创作蓝图：先有世界，再有镜头

每个 Scene 的策划卡必须回答：

1. **Concept Thesis / 核心概念**：一句话说明这个世界独特在哪里（不是「高级赛博电影感」）。
2. **Cultural Anchor / 文化锚点**：至少一个。目标抖音观众会从什么声画线索认出它？它与哪些观众的文化经验有关？
3. **Altered Reality / 现实的改变**：改变的是哪个条件？这个改变为何会使熟悉的经验触发某种情绪？
4. **Scale & Function / 尺度及用途**：人、建筑、车辆、维护设施、时间痕迹如何给出比例尺？这个空间如何被使用？
5. **Visual Discovery / 观看路径**：观众按何顺序发现画面信息（不要求有剧情反转）？
6. **Atmosphere & Sonic Physics / 声音**：低频、雨、机械共振、街声、远近层次如何让体量变得可信？
7. **STEPPS / 传播动机**：观众为什么会分享这个世界？
8. **Technical Boundary / 技术边界**：最难保住的静态结构/运动结构是什么？先用静帧验证还是用一镜验证？

**样例。** 未来城市沿用古代浑天仪来校准全城的时刻。一座山岳尺度的铜环由蒸汽活塞带动，感应器将校准信号传入青瓦街巷。清晨，茶摊上的杯沿轻颤，街口的报时钟随之响起，第一班通勤车出发。观众先认出街坊开张的节奏，再看见整座城靠什么开始一天。杯沿的轻颤与头顶缓慢转动的铜环共同传达敬畏感。

### 2.4 Three rules / 阶段性铁律

- **Scene：** 不强迫角色、剧情、反转、寓意；但必须有视觉中心、可读的空间关系、设计过的声音和足够丰富的概念细节。
- **Sequence：** 不把没有内在关联的漂亮图拼在一起；要有相同世界规则、视听母题、信息递进或主题关联。
- **Film：** 不能用「玄幻」「梦境」「留白」掩盖剧情因果空缺。人物做的事情必须符合角色已知信息和世界内部逻辑。

## 导演如何把入选想法交给摄影和声音

把八项策划答案收敛成一小段可供创意审批的处理稿。写出机位能知道什么、哪一部分世界会超出画面、一个可信后果、最后留给观众的感受。把能自由试验的细节与改变便会变成另一场戏的决定分开。提出最容易误读的地方和最小可判别测试。用户还在选点子时只给核心画面。

**示范处理稿｜水位留下的街（待试）。** 从乌篷船舷高度看一面临河的白墙，水下隐约露出一圈锈铁。船向前漂，经过第二圈、第三圈，最高那圈正拉紧一根湿绳。观众先把它们看作普通系船环，随后从不同高度、磨损和水痕看懂整条街怎样和一年年上涨的河水一起生活。让绳索吃力时的细响留在近处，最后看一眼窗台到水面只剩多远。希望留下亲近里带一点怅然的感受。

**交给下一环节。** 保住同一面墙、环的相对高度和正在受力的最高环。墙色、阴晴和船行速度可试。先用竖幅线稿辨认三高度，再试听是否能凭水声和绳响想象出船的位置。若观众只看见三只装饰环，补一条旧水线或换能看出环内磨痕的斜视点。色调在几何可读后决定。

**扩成组曲时**，给每个镜头一个新增信息，如「沿墙历史 → 全街当下水位 → 室内窗沿的剩余距离」。固定同一水位、受光侧和水声母题，改变观察距离或听音位置。剪去中间一镜后若最后一镜分量相同，重做中间镜的作用。进入叙事片时，另写人物知道什么、为何此刻必须选择、选择如何改变下一场的条件。
