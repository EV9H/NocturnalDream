# 概念脑暴

从 [创作方向与场景立项](creative-direction.md) 的 Altered Reality 标准出发。先判断用户要拓宽方向、换一个点子，还是深化已有提案。

用户给出语气、类型或美学方向时，从 [创作方向库](directions/INDEX.md) 读取对应提示词，再发散。换方向时保留用户对文字和画面表达的有效反馈，根据新方向重设情绪落点。比如温情提案里的具体观察可以带到冷峻写实中，结尾的情绪由新的空间关系决定。

## 选择发散方式

- **开放脑暴。** 从想拍的一个电影画面或想唤起的一种感受起步，找能让这份感受变具体的文化锚点，再推演改变后的世界。把当代中国城市空间、通勤、学校、集体记忆和地方感纳入发散。节俗和传统物件只在它们真正决定画面或情绪时选用。用户指定古代中国、蒸汽朋克等方向时，就在这个方向内发散。比较候选所改变的东西，例如整片环境、空间关系、时间感、城市功能或历史走向。让备选拥有不同的观看体验。
- **「再给我一个」。** 查阅 [Scene First Workbook](../../../../Studio-Reference/Scene_First_Workbook_v1.1.xlsx) 的场景清单、当前对话近期提案和相关场景记录。简要对照文化锚点、现实变化、情绪和揭示方式。优先改变锚点与变化之间的核心关系。如果用户指定了地点、题材或风格，保留该条件，在允许的范围内换一个核心关系。把用户明确拒绝的方向及其原因纳入判断。
- **深化已有提案。** 保留已认可的文化锚点、变化和情绪，结合用户的修改意见，探索更有说服力的构图、揭示方式或声画后果。如果要更换核心关系，先把它作为一个新方向提出。

## 筛选前，先把每个种子变成一个可看的瞬间

用两三句说明目标抖音观众能认出的具体锚点、一条可感知的变化、第一眼看到什么，以及随后发现什么。再写下哪一个画面或声音承载情绪。人、生活痕迹、旁白和反转都可按场景取舍。

先判断文化联系和情绪是否来自同一个核心关系。设想把锚点换成同类场景或符号，如果镜头和情绪几乎一样，继续深化文化联系。用一句话说清变化过后，这个空间或时刻为什么让人感到不同。如果一句话只能说出某件东西动了、变了或活了，继续推演它的声画后果，或者换一个种子。近景和微小变化有资格入选，前提是能承载具体的情绪经验。

用 [视觉设计](visual-design.md) 的标准检查入围想法。写清摄影机站在哪里，光从哪来，近处和远处各是什么，以及改变如何在空间、材质或声音上留下可感知的结果。比较画面辨识度、情绪和原创性，再考虑制作可行性。用 [剪辑与声音](editing-and-sound.md) 检查首眼和发现。把解释性设定压到观众实际能体验的范围。

**审美参照。** 《上海，暴雪之后》的分量来自雪改写了整个熟悉的外滩，远近都能看到同一场雪的后果。它允许观众在镜头开始时就进入改变后的世界。龙舟影子游走、麻将图案飞出、蒸笼蒸汽变成雨这批提案，把观看重点集中在物件的变化上，展现的空间和情绪都太薄。用这组反馈检查一批候选是否共用同一种小机关，即使道具和场景各不相同。

## 交付

- 先给核心画面和观看体验。用户要一个，就给一个最强方向。开放脑暴给少量有区分度的方向，并简述首选及取舍。创意提案默认用中文，按用户要求调整语言和数量。秒数、分镜和提示词等到进入镜头设计或用户明确要求时再定。
- 入选进入开发时，补齐场景策划卡、选 2–3 个与体验相连的 STEPPS 驱动，并说明最小的制作测试。保留重要决定和备选的理由。生成仍遵守技能入口中的创意与费用审批。

## 怎样从同一份 brief 得到真正不同的构想

以「江南水乡，要有夏天的潮感」为例。内部可从以下入口各推一步。对用户只呈现符合数量要求的候选。表中均为写作示范。

| 发散入口 | 核心画面 | 要保住的体验 |
| --- | --- | --- |
| 从功能推演 | 河水升到二楼以后，石埠头的系船环逐层砌进沿河房子的墙里。镜头掠过水面下最老的一环，停在如今被缆绳磨亮的那一环。 | 从同一面墙上读出几十年的水位和生活适应。 |
| 从感知推演 | 桥洞把刚经过的船声留到下一场雨。空水面上只看见雨丝在拱下消失，听见拱外近雨和拱内很远的橹声。 | 观众先确认桥下无人，再体验一个地方保存过往的寂寥。声音承担时间线索，画面须独立交代空桥与天气。 |
| 从结构推演 | 整座廊桥随涨水沿石墩升起，桥两头的台阶逐级没入河面。机位贴近岸上一阶，无需拍完整套机械。 | 让抬脚就能量出的高度一路传到整条街，产生切身的敬畏。 |

比较时优先问四件事。① 去掉标题后能否指认锚点与改变？② 改变在近处与别处有何一致后果，或在一个接触点留下何种足够丰富的细节？③ 什么具体镜头使情绪成立？④ 哪个关键关系最怕生成失败，是否能先用构图或声音草案低成本判断？若多个种子都只靠「最后东西动一下」兑现，回到功能、环境历史或感知入口重想。需要选择时，先保留最有独特观看体验的一项，说明另一项在哪个条件下更合适。不要给想象中的完播率打分。
