### 6.1 参考片拆解模板

**每看一支作品，只记录一张参考卡**：链接 / Timecode / 核心世界概念 / 尺度参照 / 环境细节 / 光位 / 色彩 / 构图 / 运动 / 声音 / 视觉发现机制 / 可迁移规则 / 不该模仿的表面特征。禁止只写「太高级」「电影感」。

### 6.2 参考矩阵，优先顺序

1. **A + D**：The Batman + Open Spaces → 一个真实夜景中发生不可能事件。
2. **A + B**：Blade Runner 2049 + L$D → 深色城市与主观梦境。
3. **B + D**：The Blaze + Welcome Home → 情绪变化驱动空间变化。
4. **A + B + D**：Crewdson + 前述作品 → 最终形成原创混合语法。
