# 阶段规划与观察指标

### 2.5 初期内容实验组合（提议，尚未验证）

- **70% Scene Studies**：高概念视觉世界和单场景探索。
- **20% Linked Sequences**：将最强场景组合成两个以上有关联的镜头 / 小型视觉组曲。
- **10% Process / Experiments**：对照实验、光影分解、世界设定片段等。

百分比用于最初的内容组合，不是平台算法规律；随着 Stage 2 成熟逐步增加组合影片，真正完整的 narrative film 保留为长期研发主线。

## 10｜首月执行：优先造世界和磨镜头（v1.1）

### Week 1：概念深度优先

- 搜集 15–20 个真正不同的高概念 Scene seed，不以「10 秒故事」作为提案形式。
- 为其中 6 个填写 Scene Blueprint；检查文化与技术概念是否实在、是否有比例尺、用途和环境声音。
- 择优 3 个概念，每个准备一张 World Sheet（材质、空间图、光位、前中后景、尺度参照）。
- **产出**：概念比较表 + 3 个明确可生成的独立场景方案。

### Week 2：各做一个有质量的 Scene

- 先拍（生成）静帧，再确定镜头运动、听觉低频与环境运动；不要一开始挑战多段连贯变形。
- 三个 Scene 可以属于完全不同的题材，但要能辨认同一作者的审美判断。
- 每条至少试两种摄影决策（例如固定机位观察 vs 缓慢抬镜），只比较一种关键变量。
- **产出**：3 条通过 QC 的高概念 Scene 或明确记录未通过原因。

### Week 3：传播实验与场景扩展

- 在适合的平台发布符合质量标准的场景作品，并记录具体的情绪、现实辨认线索及分享动机假设。
- 用观众实际反馈判断概念吸引力；不要仅看风格是否「高级」。
- 为表现最有潜力的概念补 1–2 个同世界的关联场景，先检查建筑、尺度、光与声音的连续性。
- **产出**：第一组可供 Stage 2 拼接的世界资产；尚不强制制作剧情。

### Week 4：第一支视觉组曲的概念验证

- 从某个世界挑 2–4 个镜头，组合成不依赖人物剧情的 coherent visual sequence。
- 设计统一声学母题、空间演进和镜头强弱关系，删掉只有漂亮但破坏世界规则的镜头。
- 比较单 Scene 与组合 Sequence 的观看体验和品牌识别。
- **产出**：Stage 1 Scene Library、Stage 2 试验版 Sequence，以及下一轮优先世界清单。

### 10.1 监测指标：作品表现 × 创作资产质量

| 指标 | 用途 |
|---|---|
| 3 秒留存、平均时长、完播 | 评估首屏视觉注意力与整个镜头的观看张力；按时长和平台口径分组 |
| 分享、收藏、关注转化 | 判断惊叹与社交货币是否转化为传播和账号认同 |
| 评论中的世界细节提及 | 定性检验观众是否感知尺度、文化融合、设定与氛围，而非只说「AI 好强」 |
| 重看及重复观看迹象 | 用平台实际支持的数据；如无直接指标则不凭空推断 |
| 每条可用生成镜头成本 / 失败类型 | 评估制作可持续性、技术风险和场景复用价值 |
| 世界复用资产数 | 相同地点 / 机械 / 声音 / 光学规则能否支持后续多个 Scene |

**不设虚构的行业阈值；**先建立同平台、近似时长和题材的自身基线。实验结论与审美判断分开记录。

### 10.2 阶段升级关卡

- Stage 1 → Stage 2：存在至少一个足够鲜明的原创世界，以及多个彼此兼容、QC 合格的场景和声画母题；**不是**达到任意粉丝数。
- Stage 2 → Stage 3：已有可信世界观、可复用视听设计、能独立阅读成立的 treatment / screenplay，以及可覆盖关键戏剧场景的制作能力；不因某个场景爆了就仓促拍长片。
- 长期叙事研发：可以先积累人物、社会规则与故事种子，但**不要污染早期 Scene 的视觉探索自由度**。

## 12｜下一步的优先决策（Stage 1 已优先）

1. 建立 15 个不同题材的高概念世界 seed；筛选 3 个最有原创性、尺度、细节与传播动机的 Scene。
2. 先独立完成单场景作品，用场景本身的世界构成、声音和镜头设计建立辨识度。
3. 一旦某个世界的单场景成立，再沿同一世界规则扩展第二、第三场景，组合成视觉组曲（Stage 2）。
4. **完整电影是长期目标**。等原创世界、制作能力和剧本研发成熟，再发展角色和情节；不强迫用 10 秒讲完一个故事。

**创作三元论**：Concept / World Design × Cinematic Visual DNA × STEPPS。叙事是第三阶段需要严肃建立的第四套系统，而不是所有内容形式的必要条件。
