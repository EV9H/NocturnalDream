# NOCTURNAL DREAM

**CREATIVE BIBLE / V1.1**  
**Nocturnal Dream Editorial Realism · 夜梦式风格化写实**  
**2026-11-17 · Scene-first Revision · 可长期维护的账号创作操作系统**

> **先创造值得探索的世界，再决定是否需要故事。**  
> Concept first. Build a world worth looking at. Earn the story.

**使用说明**：这是一份可迭代的创作基线，不是绝对审美教条。创意策划遵循 Concept / World Design，内容传播遵循 STEPPS，画面制作遵循 Visual DNA，发布后按数据校正。**单场景不强制剧情，短片也不强制 10 秒讲完故事。**所有工具、参数、平台及表现指标以实际测试为准。已验证的外部参考列于附录；原创创意和目标阈值为本项目的工作假设。

## 01｜项目北极星：账号到底是什么

### 1.1 一句话定位

**用具有视觉作者性的电影化写实，探索令人惊叹、可信而陌生的虚构世界；先做高概念场景，再发展视觉组曲，最终制作真正有情节深度的原创电影。**

账号是原创视觉世界与电影的长期研发工作室。AI 是制作工具，不是内容的唯一卖点；**眼下主线是 Scene / Visual Exploration，不是微剧情账号**。

### 1.2 可识别的品牌承诺

1. 每支作品先明确**它想让观众看见什么新的世界、物理关系、文化碰撞或感知尺度**。
2. 画面以空间、时间、材质、光源和人与世界的关系建立可信度。
3. 可以有人、可以无人；可以有超现实异常、也可以是完全物理可信的极端场景。**不强制每条都有主人公、道德寓意或反转。**
4. 保留六条 Visual DNA 和 A/B/D 风格，但根据题材决定如何运用，避免每条都长得像同一座阴暗地铁站。
5. 构建可扩展的世界、声音与视觉母题，逐步积累 scene library → sequence / bundle → long film 的原始素材与经验。

### 1.3 目标受众与内容场景（待实测）

- 主要候选：喜欢电影、音乐、潮流视觉、城市夜景、精致情绪短片的 18–35 岁短视频用户。
- 用户需求：情绪共鸣、审美刺激、可分享的奇异情境、值得收藏的短片。
- 平台假设：抖音 / TikTok 竖屏为主，Instagram Reels / 小红书作延展。各平台的内容比例和发布节奏应按数据而非直觉决定。
- 创始目标：用**能连续做 100 条**的创作系统，找到自己的审美指纹。

### 1.4 明确不做

- 把所有 5–10 秒 AI 视频硬塞成起承转合、角色转变、煽情文字或「跟随梦想」的励志寓言。
- 为一张好看的奇观画面临时编造不可信的人物动机或行动；未设计为何安全，就让人物走进海里。
- 空洞地堆叠赛博、巨物、寺庙、雨夜等流行标签，却没有比例尺、功能系统、生活痕迹或摄影设计。
- 每支都要有一个异常、一个反转、一个人物；或把「10 秒」误当成内容类别。
- 泛滥霓虹、假 HDR、油亮肤质、失控变形、无来源的镜头运动、权利不清的素材。

## 02｜内容理论：STEPPS 用于创作决策

| 维度 | 创作问题 | 视频内可执行的机制 | 常见失败 |
|---|---|---|---|
| S / Social Currency 社交货币 | 分享它会让我显得有什么品味或发现？ | 独到审美、反直觉揭示、令人想转给朋友的意象 | 自夸式「我做得很厉害」 |
| T / Triggers 诱因 | 生活中何时会再次想到这个系列？ | 雨夜、地铁、凌晨、某首音乐、周五的固定栏目 | 一条火后无记忆锚点 |
| E / Emotion 情绪 | 观众看完身体感受到什么？ | 惊叹、渴望、悬念、释然、苦甜情绪 | 只有漂亮画面，没有情感变化 |
| P / Public 公共性 | 能否被看到、模仿、识别？ | 系列符号、可参与的挑战、辨识度强的封面母题 | 形式复杂无法复述 |
| P / Practical Value 实用价值 | 是否值得收藏或转给需要的人？ | 少量穿插 behind-the-scenes、创作拆解 | 教程取代作品，削弱品牌调性 |
| S / Stories 故事 | 若是故事影片，观众能否复述因果与选择？ | 角色 + 动机 + 变化；世界组曲可仅暗示背景历史 | 为奇观硬塞假剧情或勉强励志 |

**每条聚焦 2–3 个主驱动**，其余可为空。高唤醒情绪更常触发传播，但长期品牌还需要审美一致性和对人物的情感投资。

### 2.1 传播框架必须服从内容类型

**Visual Spectacle / Scene**：首要考虑 Awe（惊叹，高唤醒 Emotion）、Social Currency（分享一种罕见审美发现）、Public（可复述的系列符号）；Stories 可为空，Practical Value 不必硬加。

**Visual Sequence / Worldbuilding**：靠系列母题、熟悉的世界规则、视听主题和逐渐增长的信息密度形成 Triggers / Public / Emotion；不是每一个镜头都要有剧情冲突。

**Narrative Film**：当我们确实要讲故事，再用 Stories、Emotion、Social Currency 等深入设计角色动机、因果和终局。

**通用提问**：「这条内容使观众体验到了什么独特而可以转述的东西？」优先选 2–3 个 STEPPS 驱动，不规定每条都必须有 Hook→Twist→Moral。

### 2.2 创作阶梯 / THE THREE-STAGE LADDER（核心路线）

| 阶段 | 作品单元 | 工作目标 | 是否必须有剧情 | 升级条件 |
|---|---|---|---|---|
| **Stage 1 · SCENE**（现在） | 独立高概念场景；常见 5–20 秒，也可以更久 | 建立鲜明视觉概念、可信世界、镜头与声音的质感，探索不同题材 | **否** | 已有足够原创、可复用、QC 合格的场景，以及可辨识的视觉母题 |
| **Stage 2 · SEQUENCE / BUNDLE**（下一步） | 多场景组合、视觉组曲、音乐影像；长度由内容决定，常见 30–120 秒或更长 | 建立世界内部一致性、尺度变化、节奏、场景间逻辑与声画推进 | **否**，可以有隐含叙事但不强制人物弧线 | 世界设定、视觉与声音能跨场景维持；组合后整体优于片段堆砌 |
| **Stage 3 · NARRATIVE FILM**（长期） | 有角色、因果和真实戏剧结构的完整短片或长片 | 以已成熟的视觉语言为剧情服务，处理背景、动机、选择、后果 | **是** | 故事文本独立成立；世界规则、角色行动和制作能力能支持完整影片 |

**这是能力进阶，不是产出期限。** 可以在 Stage 1 试少量长片技术，但账号初期不要为了「看起来像导演」强行编剧。长度服务概念，不由模型单次输出时长决定。

### 2.3 Scene-first 创作蓝图：先有世界，再有镜头

每个 Scene 的策划卡必须回答：

1. **Concept Thesis / 核心概念**：一句话说明这个世界独特在哪里（不是「高级赛博电影感」）。
2. **World Anchor / 现实锚点**：什么普通、可辨的生活材料让观众相信它？
3. **Unexpected Relation / 新关系**：比例、时代、文化、物理或功能上的冲突是什么？
4. **Scale & Function / 尺度及用途**：人、建筑、车辆、维护设施、时间痕迹如何给出比例尺？这个空间如何被使用？
5. **Visual Discovery / 观看路径**：观众按何顺序发现画面信息（不要求有剧情反转）？
6. **Atmosphere & Sonic Physics / 声音**：低频、雨、机械共振、街声、远近层次如何让体量变得可信？
7. **STEPPS / 传播动机**：观众为什么会分享这个世界？
8. **Technical Boundary / 技术边界**：最难保住的静态结构/运动结构是什么？先用静帧验证还是用一镜验证？

**样例（仅说明方法，非账号固定风格）：** 「未来城市中，人们仍在青瓦街巷中通勤，但整座城区被一座缓慢旋转的、山岳尺度的古代浑天仪笼罩。输送轨道和维修平台沿巨轮运行，茶杯会被它的低频机械共振震动。」这比仅仅说「赛博中式美学巨物恐惧症」多了可见的尺度、用途、生活证据和声学。

### 2.4 Three rules / 阶段性铁律

- **Scene：** 不强迫角色、剧情、反转、寓意；但必须有视觉中心、可读的空间关系、设计过的声音和足够丰富的概念细节。
- **Sequence：** 不把没有内在关联的漂亮图拼在一起；要有相同世界规则、视听母题、信息递进或主题关联。
- **Film：** 不能用「玄幻」「梦境」「留白」掩盖剧情因果空缺。人物做的事情必须符合角色已知信息和世界内部逻辑。

### 2.5 初期内容实验组合（提议，尚未验证）

- **70% Scene Studies**：高概念视觉世界和单场景探索。
- **20% Linked Sequences**：将最强场景组合成两个以上有关联的镜头 / 小型视觉组曲。
- **10% Process / Experiments**：对照实验、光影分解、世界设定片段等。

百分比用于最初的内容组合，不是平台算法规律；随着 Stage 2 成熟逐步增加组合影片，真正完整的 narrative film 保留为长期研发主线。

## 03｜Visual DNA：六条创作信条

### I. Moody Darkness / 有层次的暗

保留黑色的重量与暗部的可辨层次。通过局部光定义人的眼睛、轮廓或手，而非整体提亮。优先「有理由的光」：街灯、窗光、车灯、门缝、屏幕、反射、远处霓虹；允许诗意放大，但要能被观众直觉接受。

**检查**：关闭声音缩成手机小图，画面视觉中心（建筑/人物/装置）是否可读？是否有面积明确的亮点？黑位是否死黑？

### II. Dream Haze / 梦感空气

使用轻雾、玻璃、雨、布料、逆光、微弱光晕，制造主观记忆而不是无差别柔焦。画面清晰区域应被设计，面部轮廓和情绪不能因雾化而消失。

**检查**：如果把雾或光晕拿掉，视觉概念是否仍成立？否则可能只是滤镜而不是世界设计。

### III. Editorial Surreal Accent / 一个视觉异常

从熟悉的环境进入不可能事件：雨滴悬停、街口变成海、楼道向天空延伸、影子比人物晚一步行动。**同一镜头优先有一个视觉主导概念**，但概念可以通过多层建筑、功能与环境细节展开，不要求一定有「超现实异常」。不为降低生成难度而消灭世界的复杂性。

**检查**：能否一句话说清核心设计？世界的细节是否共同支持一个审美观点？若涉及人物，异常与其情绪有何关系？

### IV. Controlled Color Palette / 克制调色

大多数作品控制 **1 个主色族 + 1 个辅助色族 + 1 个可选点缀色**。避免高饱和全屏色光竞争。实用原则：中性色作大面积基底，肤色自然可辨，强调色只落在叙事关键处。

**基础色板（创作建议，非影像标准）**：

| 角色 | 色名 | HEX | 使用 |
|---|---|---|---|
| Base | Charcoal | `#181B20` | 服装、阴影、城市 |
| Base | Midnight Blue | `#1C2835` | 夜空、冷环境光 |
| Secondary | Desaturated Teal | `#3E6062` | 玻璃、潮湿空气 |
| Secondary | Burgundy | `#612A3A` | 布料、情绪关键物 |
| Accent | Amber | `#D69B62` | 窗光、钨丝、皮肤暖反光 |
| Accent | Silver | `#BFC7CD` | 雨滴、月光、金属高光 |

### V. Human-Centered Intimacy / 人的尺度与情绪（可有人，也可无人）

有人物时优先具有可读情绪和明确空间关系的动作；没有主人公的世界奇观中，可用人群、窗灯、维护工人、交通、风中衣物等**人类尺度与生活痕迹**建立亲密感。大景展示世界，小细节让世界有重量；**不要求每个 Scene 拍人物脸部特写**。

**检查**：观众能否感知这个空间如何被生活、使用或影响？如果是故事片，人物是否有可信欲望？

### VI. Elegant Unreality / 优雅的不真实

特效应该像摄影机偶然捕捉到了一个不可能但可信的世界，而不是在向观众炫耀合成效果。尽量由真实材质、可理解的重力、稳定透视、环境接触和光线互动来承载异常。

**检查**：异常物是否在周围环境中投下合理的影子、反射或交互？人物是否有反应？

## 04｜三套可复用 Style Preset

### A / MIDNIGHT WITNESS — 都市暗场见证

- **主要情绪**：孤独、悬念、压抑、隐秘温柔。
- **场景**：雨夜纽约、小巷、停车楼、空地铁、城市高架下方。
- **光线**：侧后方钨丝街灯 / 门缝光 + 冷色环境填充；深黑但保留眼睛。
- **色彩**：charcoal + midnight blue + amber（占比由场景决定）。
- **构图**：负空间、建筑对称、远景中的孤独人物；穿插克制近景。
- **运动**：缓慢侧移 / dolly-in / 固定机位，不滥用推拉摇。
- **超现实母题**：影子延迟、灯光逆向流动、街道尽头出现不存在的门。
- **避免**：全屏蓝橙对冲、雨滴不受物理影响、黑到看不见脸。

### B / VELVET AFTERIMAGE — 柔软梦境余像

- **主要情绪**：怀念、爱、失落、重逢、短暂幸福。
- **场景**：透雾车窗、午夜公寓、海边步道、卧室窗帘、清晨出租车。
- **光线**：窗外冷光 + 室内柔暖光；逆光纱帘；高光轻微漫散。
- **色彩**：desaturated teal + amber + burgundy / muted blush。
- **构图**：玻璃层、遮挡、手与脸的中近景、柔和前景虚化。
- **运动**：安静的人物动作 + 浮游式小幅跟拍，允许极短慢动作。
- **超现实母题**：记忆中的同一个人短暂出现、雨滴静止、倒影比现实多一个人。
- **避免**：无处不在的 bloom、五官变形、悬浮镜头造成广告感。

### D / EDITORIAL RUPTURE — 现实中的优雅裂缝

- **主要情绪**：惊叹、陌生化、权力感、荒诞、黑色幽默。
- **场景**：极简室内、写字楼大厅、酒店走廊、无人秀场、巨型几何空间。
- **光线**：方向明确的硬光 / 聚光；轮廓照明；有设计的影子。
- **色彩**：charcoal + silver + 单个强调色 burgundy / amber。
- **构图**：严格对称、中心人物、强透视、规整的大块负空间。
- **运动**：机位固定优先，环境发生不可能变化；偶尔机械式跟拍。
- **超现实母题**：电梯门后是海洋、房间折叠、重力仅对一个物体反转。
- **避免**：无限变形、特效同时乱飞、镜头失控、人物变成 CGI 模特。

**融合策略**：每条以一个 Style Preset 为主导（70%），另一个辅助（30%）；第三个仅作为微量意象参考。比例是审美描述，不是模型参数。

## 05｜摄影与声音的具体标准

### 5.1 镜头术语与使用条件

- **24–28 mm 等效视角**：建筑、环境、孤独感；靠近人物时谨防夸张人脸。
- **35–50 mm 等效视角**：中景、半身、自然人物；作为日常主力。
- **65–85 mm 等效视角**：情绪近景、压缩背景、城市光斑；注意主体与环境仍有联系。
- **机位高度**：人物视线附近最自然；低角度仅在权力关系或结构需要时使用。
- **运镜**：每个镜头只选一种明确运动，优先 locked-off、slow lateral track、slow dolly-in、gentle handheld。避免 simultaneous orbit + zoom + crane + pan。
- **景深**：将焦点落在眼睛 / 手 / 关键物上；不要让整片画面都模糊。
- **质感**：适度 grain、controlled halation、soft highlight roll-off、真实运动模糊；不要用 8K / masterpiece 代替摄影指令。

### 5.2 光线工作卡（开拍前必须填写）

1. **Motivation**：观众以为光从哪里来？
2. **Direction**：主光相对人物的方向（例如 camera-left 45° rear）。
3. **Quality**：hard / diffused / bounced / reflected。
4. **Ratio**：高对比还是低对比？暗部有无可读细节？
5. **Color**：光源的冷热关系如何服务情绪？
6. **Interaction**：超现实物与光如何互相影响？

### 5.3 剪辑与声音

- 先剪情绪节奏，再剪运镜花样。用停顿制造张力，用变化制造释放。
- **Scene** 的节奏可以是长时间观察、缓慢揭示、声音先行、单次尺度曝光，**不强制** 0–2 秒 Hook、末尾 Twist。**Sequence** 追求跨镜头的感知递进；**Film** 根据剧本节奏设计转折。长度以概念和实际观感为准。
- 音乐可使用原创 EDM、原创氛围音或有合法授权的素材；不默认引用受版权保护的热门音乐。
- 让音效与不可能事件建立实体感：鞋底踏水、远处列车、布料、潮湿的呼吸、金属低鸣、空间回声。
- 配字幕时不堆旁白；字幕短，优先为画面留空间。

### 5.4 画面质检关卡（每镜头）

| 检查项 | Pass 标准 |
|---|---|
| Face | 人脸轮廓 / 五官位置在镜头间一致，没有突然换人 |
| Hands & Anatomy | 手指数量、关节方向、人体比例无明显异常 |
| Temporal | 背景物件、服装、饰品在连续帧间稳定 |
| Lighting | 光源方向和人物阴影一致，暗部保留必要细节 |
| Physics | 脚底接地、布料、雨、反射、超现实物有内部逻辑 |
| Motion | 摄影机轨迹可理解，运动模糊与动作一致 |
| Art Direction | 符合主 Style Preset，不出现泛滥霓虹 / 塑料感 |
| Concept / World | 核心概念鲜明；空间、尺度、功能细节有一致逻辑；故事片另检人物动机与因果 |
| Delivery | 竖屏安全区、字幕可读、没有水印或版权风险 |

**任一硬性问题（空间时序崩坏 / 明显人体故障（若有人）/ 权利风险）出现即不发布**。镜头可只重做局部，而非整片无限重抽。

## 07｜模型无关的 Prompt 体系（核心资产）

### 7.1 分层 Prompt 结构

**A. Identity Lock（人物身份）**：当用户提供获授权角色照片时，描述持续不变的脸部特征、发型、年龄感、身体比例；优先使用模型支持的 reference image / character reference / first-frame 机制。不根据照片猜测敏感身份。

**B. World / Reality Anchor（世界锚点）**：地点、时间、天气、材质、可信物理。

**C. Scene / Discovery（观看什么）**：Scene 说明核心现象、观察路径、运动或环境变化；Sequence 说明场景衔接；只有 Narrative Film 必须写角色目标、动作、情绪转折。

**D. Art Direction（视觉预设）**：Style Preset + 配色关系 + 服装 + 环境细节。

**E. Lighting（光位）**：Motivated key + ambient fill + shadow readability + reflection logic。

**F. Camera（摄影）**：景别、视角、镜头运动、焦点主体。

**G. World / Surreal Rule（世界规则）**：声明尺度、功能、交通、机械或文化逻辑；若有超现实事件，再解释它如何作用于现有物理环境。

**H. Constraints（失效约束）**：连贯性和常见 AI 瑕疵预防，不依赖长串无关 negative keywords。

### 7.2 Master Prompt — Scene-first（当前默认）

```text
[PROJECT] NOCTURNAL DREAM / [WORLD_ID] / [SCENE_ID]
FORMAT: Independent Visual Scene (not a story trailer); [duration], [aspect ratio].

CONCEPT THESIS:
[One extraordinary visual-world idea, culturally and architecturally specific.]

REALITY ANCHOR & SCALE:
[Location, recognizable everyday details, functional architecture, small human/vehicle references for scale, wear and maintenance traces.]

WORLD DESIGN:
[Materials and era, technologies and their function, topology, foreground/midground/background hierarchy. If impossible, define its physical boundary and environmental consequences.]

VISUAL DISCOVERY:
[Where camera begins; what becomes visible as time passes; what must remain stable. This may be pure observation with NO twist.]

ART DIRECTION & LIGHT:
[Dominant Nocturnal Dream style preset, restrained palette, motivated key light and shadow structure; material response.]

CAMERA & MOTION:
[Composition, perspective, one justified movement or locked-off shot, depth and physically plausible motion.]

SOUND / SCALE:
[Environmental sounds, distance, mechanical low end, reverb, temporal dynamics; no forced voiceover or moral line.]

CONTINUITY / AVOID:
[Architecture, proportions, scale, fixed landmarks, consistent mechanics, natural material response; avoid arbitrary morphing, fake HDR, CGI gloss, unmotivated neon.]
```

**Story / Film 才额外要求：** character objective / established world rules / causal chain / choice / consequence / ending. 不把这些栏目强制套用到单场景。

**特别注意：** 输入视频模型的最终 Prompt 应按模型特性简化。Scene 的概念和世界复杂度来自构思与参考图设计，而不是每次贴 800 字形容词。

### 7.3 三套风格预设英文片段

**MIDNIGHT WITNESS**

```text
Restrained urban noir, deep but readable charcoal shadows. A warm practical streetlight shapes one side of the subject; cool night ambience gently separates the silhouette. Wet stone and glass reflect light without neon overload. Deliberate negative space, quiet tension, tactile realism. Slow lateral tracking or a composed locked-off frame.
```

**VELVET AFTERIMAGE**

```text
Poetic dreamlike realism grounded in a believable interior or street. Soft window light, translucent curtain or rain-streaked glass, restrained highlight halation, subtle atmospheric haze. Natural skin tones, muted teal and warm amber relationship, intimate gestures, gentle breathing room. A single uncanny detail emerges as if recalled from memory.
```

**EDITORIAL RUPTURE**

```text
High-end surreal editorial filmmaking inside a credible minimalist architectural space. Graphically controlled framing, sculptural directional light, deep shadows with precise highlights, limited charcoal-silver-burgundy palette. The camera remains calm while exactly one impossible physical event transforms the scene. Elegant visual tension, convincing materials and contact shadows.
```

### 7.4 人脸一致性：操作优先级

1. 使用得到肖像授权的清晰人像参考，确保是同一人、相近光照、尽量无强滤镜。
2. 尽量先制作 **hero reference frame**（稳定脸 + 发型 + 服装 + 环境），再做 image-to-video；多镜头复用该参考。
3. 全片保持一致的身份描述，减少每镜重新定义脸；优先中景、侧脸、背影与特写交替，避开连续大幅头部旋转。
4. 单次生成短镜头，控制动作复杂度；优先轻动作而非打斗、多次遮挡或极端镜头变形。
5. 对关键帧与关键脸进行人工对比；有 morph、眼距跳变或脸型漂移则重生该镜头。
6. 不在未获许可时模拟真实人物的误导性行为；必要时标明 AI 合成。

### 7.5 生成循环

**World Concept → Reference Research → World Sheet → Keyframe / Layout Test → Single Scene → Visual QC → Sound Design → Publish / Archive → Learn**。人物不是每条必选；**长时间镜头与多场景组合**按概念需要单独设计。先以低成本草稿筛创意，再用高规格生成关键镜头；具体 credits、模型和分辨率遵循实际套餐。

## 08｜v1.0 Pilot 档案（保留为技术实验，不是 v1.1 创作路线）

**重要：本节四个 Pilot 仅作为 v1.0 技术探索记录保留，不代表已批准的故事、项目排期或首发系列。** 地铁与海洋测试验证了画面可能性，但空间连续性和剧情动机没有成立。尤其「人走进车门后的海」若没有事先确立安全机制和行动动机，会让人担心溺水；不能靠配煽情文字补救。以下旧概念暂时冻结，不作为 Stage 1 的默认任务。

### PILOT 01 / LAST TRAIN TO THE SEA｜开往海的末班车

**旧版技术测试配置（非已批准故事）**：A 70% + D 30%｜STEPPS 初拟 Emotion + Stories + Social Currency  
**一句话故事**：深夜一个人等待末班车，车门打开，车厢里是一整片潮汐。  
**情绪**：疲惫 → 困惑 → 释然。 **视觉异常**：列车内部是海，不是现实车厢。

1. **S01 0–4 s / Hook**：空荡地下站台，女生独自站在黄色安全线后，灯逐盏熄灭，只有远处车灯出现。35 mm wide, locked-off; dim fluorescent practicals; charcoal / teal.
2. **S02 4–8 s / Establish**：门打开，门内是一片平静的深蓝海面，海水没有越过车门门槛。静止广角正面构图，强调边界与接触逻辑。
3. **S03 8–13 s / Reaction**：她的脸被海面反光轻轻照亮，向前试探一步；50 mm close-medium, slight dolly-in, soft blue bounce + warm residual platform light.
4. **S04 13–18 s / Release**：一只小浪花在门边触及她鞋尖，画面切黑，仅留下潮声；鞋与水接触真实，单一动作。

**镜头 Prompt（S02）**：

```text
Vertical cinematic film frame, an empty underground subway platform at midnight, one solitary woman stands behind the yellow line, same hair and dark long coat throughout. A train arrives and the doors open; beyond the rectangular door frame there is a calm, deep-blue ocean extending to the horizon instead of a train carriage. The sea obeys one impossible boundary: it stops precisely at the train threshold, with soft reflected light spilling onto wet tile. Locked-off symmetrical wide shot, 35mm perspective, charcoal shadows, muted teal atmosphere, a narrow warm platform light, believable architecture and reflections. Stylized cinematic realism, elegant unreality, restrained visual effects. No extra passengers, no face deformation, no chaotic motion, no excessive neon or CGI gloss.
```

**封面文案候选**：「最后一班地铁，开往哪里？」  
**AB 试验**：Hook A 直接露出海；Hook B 先露女生的反应再揭示海。其余保持不变。

### PILOT 02 / THE WINDOW REMEMBERS｜窗户记得你

**主风格**：B 70% + A 30%｜**STEPPS**：Emotion + Stories  
**一句话故事**：窗外雨夜，她在玻璃倒影中看见曾经和自己并肩的人，回头却无人。  
**情绪**：平静 → 怀念 → 留白。**异常**：玻璃倒影比现实多一个人。

1. **S01**：窗上的雨滴与城市暖光，半透明倒影，轻微平移。
2. **S02**：女主将手贴上玻璃，倒影里另一只手也与她相贴。
3. **S03**：她回头，房间空无一人；固定机位，环境不重构。
4. **S04**：倒影里的手慢慢放开，玻璃只剩水纹；音效收束。

```text
A young woman in a dim apartment at night gently places her palm against a rain-streaked window. The room is empty, yet the glass reflection shows a second person standing beside her; only the reflected presence is impossible. Muted teal city night beyond the window, warm practical lamp behind her, subtle halation around distant highlights, realistic water droplets and layered reflections. A patient 50mm medium close-up, almost locked-off camera, quiet melancholy, natural skin texture, precise face consistency, no ghostly horror makeup, no excessive bloom, no morphing furniture.
```

**封面文案**：「如果窗户记得一个人？」  
**AB 试验**：带文案 vs 无文案；关注完播与分享是否改变。

### PILOT 03 / THE ROOM FOLDS｜折叠的房间

**主风格**：D 70% + A 30%｜**STEPPS**：Social Currency + Emotion + Stories  
**一句话故事**：人物在静止房间中系好外套，身后整个房间像纸一样沿光影线折叠。  
**情绪**：克制 → 惊叹 → 不动声色。**异常**：建筑空间只沿一条明确折线改变。

1. **S01**：中心对称，人物站在冷调走廊，光线像舞台聚光。
2. **S02**：她扣上衣扣，墙面沿一条清晰折线向内合拢；固定镜头。
3. **S03**：地面投影随折叠改变，但人物和服装不变。
4. **S04**：空间恢复正常，她看一眼镜头转身走出。

```text
A fashion-editorial woman stands perfectly still in a minimalist charcoal-gray corridor, wearing a tailored burgundy coat. The camera is locked off, symmetrical 40mm perspective, sculptural hard side-light creates long precise shadows. She quietly closes one button of her coat. Only the far wall folds inward along a single visible architectural seam, like heavy material bending with physical weight; its shadow updates accurately on the floor. Her face, clothing and body remain stable. High-end cinematic realism with one restrained surreal event; tactile surfaces, subtle film texture, no spinning camera, no melting geometry, no glossy synthetic skin.
```

**封面文案**：「她系上扣子，房间就变了。」  
**AB 试验**：固定机位 vs 极轻微侧移；观察画面稳定性及留存。

### PILOT 04 / THE SHADOW ARRIVES LATE｜迟到的影子

**主风格**：A 70% + B 30%｜**STEPPS**：Social Currency + Triggers + Stories  
**一句话故事**：在深夜斑马线等灯的人走开了，影子却还站在原地一秒钟。  
**情绪**：日常 → 诧异 → 黑色幽默。**异常**：影子比主人晚行动。

1. **S01**：空旷路口，只有一个信号灯，背后暖街灯投下长影子。
2. **S02**：绿灯亮，人开始走，影子留在原位不动。
3. **S03**：人物察觉异常，缓缓回头；光方向不变。
4. **S04**：影子像迟到者一样急忙追上去，切黑留脚步声。

```text
A lone commuter stands at a nearly empty crosswalk after midnight, lit by one warm sodium streetlamp behind camera-left. Deep charcoal night, wet asphalt, quiet distant traffic, a believable long shadow across the road. The pedestrian takes one step forward, but the shadow remains standing in the original position for exactly one beat before it follows. Everything else obeys realistic physics; the streetlamp remains fixed and all reflections are consistent. Medium-wide locked-off framing, 35mm perspective, gentle grain, subtle melancholy with dry surreal humor. No extra moving shadows, no object flicker, no face change, no excessive neon.
```

**封面文案**：「连影子都不想上班了。」  
**AB 试验**：严肃氛围配音 vs 黑色幽默字幕；观察分享人群变化。

## 10｜首月执行：优先造世界和磨镜头（v1.1）

### Week 1：概念深度优先

- 搜集 15–20 个真正不同的高概念 Scene seed，不以「10 秒故事」作为提案形式。
- 为其中 6 个填写 Scene Blueprint；检查文化与技术概念是否实在、是否有比例尺、用途和环境声音。
- 择优 3 个概念，每个准备一张 World Sheet（材质、空间图、光位、前中后景、尺度参照）。
- **产出**：概念比较表 + 3 个明确可生成的独立场景方案。

### Week 2：各做一个有质量的 Scene

- 先拍（生成）静帧，再确定镜头运动、听觉低频与环境运动；不要一开始挑战多段连贯变形。
- 三个 Scene 可以属于完全不同的题材，但要能辨认同一作者的审美判断。
- 每条至少试两种摄影决策（例如固定机位观察 vs 缓慢抬镜），只比较一种关键变量。
- **产出**：3 条通过 QC 的高概念 Scene 或明确记录未通过原因。

### Week 3：传播实验与场景扩展

- 在适合的平台发布符合质量标准的场景作品，并记录 Awe / Social Currency 等具体假设。
- 用观众实际反馈判断概念吸引力；不要仅看风格是否「高级」。
- 为表现最有潜力的概念补 1–2 个同世界的关联场景，先检查建筑、尺度、光与声音的连续性。
- **产出**：第一组可供 Stage 2 拼接的世界资产；尚不强制制作剧情。

### Week 4：第一支视觉组曲的概念验证

- 从某个世界挑 2–4 个镜头，组合成不依赖人物剧情的 coherent visual sequence。
- 设计统一声学母题、空间演进和镜头强弱关系，删掉只有漂亮但破坏世界规则的镜头。
- 比较单 Scene 与组合 Sequence 的观看体验和品牌识别。
- **产出**：Stage 1 Scene Library、Stage 2 试验版 Sequence，以及下一轮优先世界清单。

### 10.1 监测指标：作品表现 × 创作资产质量

| 指标 | 用途 |
|---|---|
| 3 秒留存、平均时长、完播 | 评估首屏视觉注意力与整个镜头的观看张力；按时长和平台口径分组 |
| 分享、收藏、关注转化 | 判断惊叹与社交货币是否转化为传播和账号认同 |
| 评论中的世界细节提及 | 定性检验观众是否感知尺度、文化融合、设定与氛围，而非只说「AI 好强」 |
| 重看及重复观看迹象 | 用平台实际支持的数据；如无直接指标则不凭空推断 |
| 每条可用生成镜头成本 / 失败类型 | 评估制作可持续性、技术风险和场景复用价值 |
| 世界复用资产数 | 相同地点 / 机械 / 声音 / 光学规则能否支持后续多个 Scene |

**不设虚构的行业阈值；**先建立同平台、近似时长和题材的自身基线。实验结论与审美判断分开记录。

### 10.2 阶段升级关卡

- Stage 1 → Stage 2：存在至少一个足够鲜明的原创世界，以及多个彼此兼容、QC 合格的场景和声画母题；**不是**达到任意粉丝数。
- Stage 2 → Stage 3：已有可信世界观、可复用视听设计、能独立阅读成立的 treatment / screenplay，以及可覆盖关键戏剧场景的制作能力；不因某个场景爆了就仓促拍长片。
- 长期叙事研发：可以先积累人物、社会规则与故事种子，但**不要污染早期 Scene 的视觉探索自由度**。

## 11｜制作 SOP / 发布前签字标准

### 11.1 Pre-production

**Scene 必须完成**：Concept Thesis / 世界锚点与尺度 / 观众的视觉发现路径 / STEPPS 主轴 / Style Preset / 光位与材质 / 环境声 / 关键帧与技术风险 / 预算上限。若出现真人，再检查肖像授权；若升级叙事影片，再要求 treatment、人物动机和因果链。

### 11.2 Generation

**必须完成**：记录模型、版本、seed（若可用）、尺寸、时长、参考图、提示词、生成次数及成本；镜头间 identity、服饰、场景不变项一致；只修改被测试的变量。

### 11.3 Post-production

**必须完成**：时间顺序与节奏 / 人物与布景连续性 / 皮肤和黑位 / 环境与动作音效 / 音乐权利 / 字幕安全区 / 竖屏预览 / 无误导性肖像问题。

### 11.4 Publish / Review

**必须完成**：封面、标题、归属系列、实验标签、发布时间、数据采集口径；发布 24 h / 72 h / 7 d 看趋势而非盯瞬时波动。涉及明确合成或真实人物易被误认的场景时，按适用平台规则和当地法律进行 AI 内容标注。

### 11.5 可量化的 100 分审片卡（内部主观量表）

- 核心概念原创性与视觉信息密度：25
- 空间尺度、功能细节与世界可信度：20
- 光影 / 色彩 / 镜头构图：20
- 时序连续性、材质与运动真实：15
- STEPPS 传播动机与记忆锚点：10
- 声音设计与品牌辨识度：10

**发布硬门槛**：没有明显时序破坏、严重人体错误或未授权素材等风险；场景主观评分 ≥ 80 才进入发布候选。对无人场景不评「人物身份」，不将评分视为观众数据。分数用于团队统一语言，不能替代真实观众数据。

## 12｜下一步的优先决策（Stage 1 已优先）

1. **暂停将地铁海洋技术样片包装成电影**。它可以留在素材库作为生成测试，但不强行补一段煽情剧情。
2. 建立 15 个不同题材的高概念世界 seed；筛选 3 个最有原创性、尺度、细节与传播动机的 Scene。
3. 先独立完成单场景作品，用场景本身的世界构成、声音和镜头设计建立辨识度。
4. 一旦某个世界的单场景成立，再沿同一世界规则扩展第二、第三场景，组合成视觉组曲（Stage 2）。
5. **完整电影是长期目标**。等原创世界、制作能力和剧本研发成熟，再发展角色和情节；不强迫用 10 秒讲完一个故事。

**创作三元论**：Concept / World Design × Cinematic Visual DNA × STEPPS。叙事是第三阶段需要严肃建立的第四套系统，而不是所有内容形式的必要条件。
