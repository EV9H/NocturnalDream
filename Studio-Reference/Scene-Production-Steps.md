# Nocturnal Dream · 单场景制作步骤

工作室拍的是**有文化根基的 Altered Reality**。先找到目标抖音观众能够认出的现实关系，再想象改变其中一个条件，会怎样改变他们看待这个地方或这段经验的方式。一处地方可以通过地理、建筑用途、共同记忆、声音或历史传统被认出。空镜也可以成立。

## 1. 从文化经验提出画面

开放脑暴时给少量真正不同的候选，用户要一个就选一个。每个提案用几句话讲清：**谁熟悉什么？现实中这两样东西有什么关系？哪条条件改变了？观众会凭哪个声画细节认出改变，并产生什么感受？**

《上海，暴雪之后》的根基是人站在外滩、隔着黄浦江望向陆家嘴的观看经验。异常深雪快埋住脚边的波形护栏；抬眼后还能看见同一场雪压在对岸屋顶。观众可以从身边一个可估量的高度，感到整座熟悉城市的寂静。构思古代巨构时，也可以从城门如何调度进出、地方水工如何顺应水位等具体关系推演出新的城市。用到真实制度、工艺或地点时查清参考，把虚构的变化写明。

**选题测试。** 把地名或文化物件换掉，问「画面里究竟会失去哪层意思？」如果只需要换招牌就能照拍，回头找真正参与变化的地理、用途或经验。只有视觉奇观的种子先留在草稿里。

## 2. 批准书面方向，确定最难的一件事

由 agent 写一段处理稿，Evan 选方向。写清机位、第一眼、随后看懂的关系、听点和最后值得停留的瞬间。复杂的世界可以只给一个视点，时长随观看需要决定。选出最怕拍丢的一件事，写成可回答的审片问题。新场景获得书面方向认可后再生成。进入制作时参考 Scene First Workbook，把 production checklist、简报和版本放在对应的 Scenes 目录。

## 3. 给参考图分工，做最小测试

每个新场景在进入生成前都要有一份可直接查看的视觉基准。可以使用找到的参考图、可用的首帧，或用程序、3D、摄影和合成自制一张。记录每张图控制的内容，并注明它是外观参考、构图预演还是可以直接输入模型的首帧。

为真实地点选一张能验证空间关系的参考，再按需要补材质、光源或运动参考。构图风险先用草图或关键帧判断；运动风险先测试动作发生的那一段。只有前后状态都决定观众能否看懂时才准备成对布局。例如《会靠岸的街》要能对照固定岸沿、轮胎护舷与整块移动的市场甲板。港口关系应在两种状态下都清楚。

## 4. 按一个问题生成和选 take

当前可从 Higgsfield / Seedance 路线起步。先说明实际模型、输出数量和报价或费用上限，取得单独的明确支出批准。记录实际提交的 prompt、参考图及其用途、画幅、时长、分辨率、音频开关、费用和输出。无法核实的设置标为未知。

看片先按正常速度判断文化线索和改变能否同时读懂，再逐帧看最要紧的接触、遮挡或运动。以《向上漏水》为例，水珠向上的路径成立，触管时的变形难辨；再试时应针对触点。若观众已经看清特效，仍说不出这件事对那个地方意味着什么，就返回立项环节。

## 5. 剪画面，定声音，在手机上完成一遍

- **画剪。** 用熟悉的剪映专业版或 DaVinci Resolve，对比原 take 和一个有明确目的的剪法。保留足够时间，让观众先认出锚点，再读出它受到了什么影响。单镜到底也可以是最终剪法。
- **声音。** 在构思时决定从哪里听，画剪稳定后再做细同步。先听现有音轨，再按需要用 Ableton Live 分层处理场所底声、动作声与音乐。外滩可比较近处鞋底压雪与停步后显出来的远江声。若场景的文化记忆由声音触发，保住那道声音的位置、音色和进入时机。
- **导出。** 留下选定剪版和对应混音，核对实际导出的画幅、时长与音轨。手机上静音看一次构图，正常外放听一次完整体验。记录不同时刻能读到的细节，决定成片、局部返修或再拍。

## 6. 让观众复述，再决定下一步

让未听过设定的人先看一遍，问「你认出了什么？后来发现了什么？哪个地方让你有感觉？」记下原话，再与创作意图比对。观众可能感受到另一种情绪；先判断差异来自自己的预设，还是线索在成片里太弱。记录要重复的做法、失效之处、下一次只改变什么。完成、获准发布、已发布分别记录。多个独立场景共享世界规则与声画母题时，再考虑扩展为组曲。

**第一次走通流程的建议。** 先用《上海，暴雪之后》Take 07 私下试剪，比较原开头与缩短约一秒的开头，保留一个清楚的脚步和完整的对岸停留，再试听两版。该场景当前暂缓发布。之后可用《会靠岸的街》走一次从文化立项到导出的完整流程；选题和生成仍依实际批准执行。
